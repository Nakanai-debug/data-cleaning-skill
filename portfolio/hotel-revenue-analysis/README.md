# Hotel Revenue Analysis — synthetic demo

**Interview focus:** occupancy, ADR and RevPAR by month. This is a demonstration project with synthetic data, not hotel operational data.

- Occupancy = sold room nights / available room nights.
- ADR = room revenue / sold room nights.
- RevPAR = room revenue / available room nights.

The runnable `analyze.py`, sample `hotel_monthly.csv` and outputs are included in the companion **DA_Portfolio_Interview_2026-11-03.zip** interview bundle prepared separately. Code and data are not yet uploaded to this GitHub folder.

**Interview discussion:** distinguish rate effects from occupancy effects; confirm KPI definitions, data granularity and seasonality before recommending action.
